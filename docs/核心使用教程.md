# TallyTrail Core 使用教程

本教程面向要在 Core 之上构建 CLI、Android、Web 或测试程序的开发者。所有业务规则都在 Core 内，UI 层只负责收集输入、调用 `CoreHandle`、展示返回值。

- 包名：`tallytrail-core`
- 入口：`tallytrail_core::CoreHandle`
- 金额：`i64` 分
- 时间：UTC 秒时间戳（`i64`）
- ID：UUID v4 字符串

完整可运行代码见 [`Core/examples/quickstart.rs`](../Core/examples/quickstart.rs)：

```bash
cargo run -p tallytrail-core --example quickstart
```

## 1. 添加依赖

同一 Workspace 内直接引用：

```toml
[dependencies]
tallytrail-core = { path = "../Core" }
chrono = { version = "0.4", default-features = false, features = ["clock", "std"] }
```

Core 自身只依赖 `rusqlite`（bundled SQLite）、`rusqlite_migration`、`chrono`、`uuid`，不依赖任何 UI 库。

## 2. 打开与关闭数据库

```rust
use tallytrail_core::CoreHandle;

let core = CoreHandle::open("my.db")?;
// ... 调用 API ...
core.checkpoint()?; // 可选：关闭前把 WAL 写回主文件
```

`CoreHandle::open` 会：

1. 打开或创建 SQLite 文件；
2. 启用外键、WAL、`busy_timeout` 等 PRAGMA；
3. 通过 `rusqlite_migration` 执行版本迁移。

`CoreHandle` 可 `Clone`，内部是 `Arc<Mutex<Connection>>`，可以跨线程共享。所有写操作都在单个事务中完成；事务失败会自动回滚。

### 关闭与备份

- 最后一个 `CoreHandle` 析构时会尝试 checkpoint。
- 直接拷贝 `.db` 文件前，务必调用 `checkpoint()` 或确保程序已正常关闭；否则最近的写入可能还在 `-wal` 文件中。
- 不建议在程序运行时直接复制数据库文件。

## 3. 金额与时间

### 金额

```rust
let amount_cents: i64 = 4_550; // 45.50 元
```

- 输入输出的金额全部是**分**，不要传浮点数。
- 累加/累减使用 `checked_add` / `checked_sub`；溢出返回 `CoreError::AmountOverflow`。
- 展示时自行除以 100，或参考 CLI 的 `format_cents`。

### 时间

Core 只接受 UTC 秒时间戳。用 `chrono` 构造：

```rust
use chrono::{TimeZone, Utc};

let at = Utc.with_ymd_and_hms(2026, 10, 1, 12, 30, 0)
    .unwrap()
    .timestamp();
```

UI 层负责把用户输入的本地时间转换为 UTC；Core 内部所有时间桶、预算周期都按 UTC 计算。

### 时间范围

所有统计接口使用左闭右开区间 `[from_at, to_at)`：

```rust
let month_start = Utc.with_ymd_and_hms(2026, 10, 1, 0, 0, 0).unwrap().timestamp();
let month_end   = Utc.with_ymd_and_hms(2026, 11, 1, 0, 0, 0).unwrap().timestamp();
```

## 4. 账户

```rust
use tallytrail_core::{AccountType, CreateAccountInput};

let bank = core.create_account(CreateAccountInput {
    name: "招商银行".into(),
    account_type: AccountType::Bank,     // BANK / CASH / E_WALLET / CREDIT / REIMBURSE_SOURCE / OTHER
    currency: Some("CNY".into()),        // 省略默认 CNY
    initial_balance_cents: 1_000_000,    // 10000.00 元
})?;
```

- 账户币种创建后不可修改。
- 信用卡可用负的初始余额表示欠款。
- `REIMBURSE_SOURCE` 用于公司/第三方报销来源账户。
- 账户可以停用（`set_account_active(false)`）；停用后不能用于新交易，历史数据保留。
- `list_accounts(include_inactive)` 返回账户列表。

## 5. 分类与标签

### 两级分类

```rust
use tallytrail_core::{CategoryKind, CreateCategoryInput};

let food = core.create_category(CreateCategoryInput {
    name: "餐饮".into(),
    parent_id: None,                    // 一级分类
    kind: CategoryKind::Expense,
    sort_order: 0,
})?;

let lunch = core.create_category(CreateCategoryInput {
    name: "午餐".into(),
    parent_id: Some(food.clone()),      // 二级分类
    kind: CategoryKind::Expense,        // 必须与父级一致
    sort_order: 0,
})?;
```

规则：

- 最多两级；二级分类的 `kind` 必须与父级一致。
- 交易可以挂一级分类，也可以挂二级分类。
- 一级分类统计自动包含直接挂在其下的交易和所有二级分类的交易。
- 已引用（交易或预算）的分类不能删除，也不能修改 `kind`，返回 `CategoryInUse`。
- 分类可停用；停用不影响历史统计。
- 同一父级下名称唯一（实现使用大小写不敏感比较）。

### 标签

```rust
let tag = core.create_tag("出差".into())?;

core.rename_tag(tag.clone(), "差旅".into())?;
core.delete_tag(tag)?; // 只解除关联，不删除交易
```

标签名称大小写不敏感唯一，不参与预算或金额统计，只用于流水筛选和展示。

## 6. 支出、收入与转账

### 普通支出

```rust
use tallytrail_core::{CreateExpenseInput, SettlementInput};

let txn = core.create_expense(CreateExpenseInput {
    occurred_at: at,
    category_id: lunch.clone(),
    note: Some("工作日午餐".into()),
    total_amount_cents: 4_550,
    currency: None,                    // 默认 CNY
    actual_amount_cents: None,         // 同币种时可省略
    settlements: vec![SettlementInput {
        account_id: wallet.clone(),
        amount_cents: 4_550,
    }],
    tag_ids: vec![tag.clone()],
})?;
```

约束：

- 至少一条结算行，金额必须为正。
- 同一交易的所有结算账户币种必须一致。
- 结算行金额合计必须等于 `actual_amount_cents`。
- 支出只能挂 `CategoryKind::Expense` 分类。

### 组合支付

多张卡/账户共同支付，只需给多条结算行：

```rust
settlements: vec![
    SettlementInput { account_id: bank.clone(),   amount_cents: 30_000 },
    SettlementInput { account_id: wallet.clone(), amount_cents: 15_500 },
],
actual_amount_cents: Some(45_500),
```

### 境外消费（双金额）

```rust
let txn = core.create_expense(CreateExpenseInput {
    occurred_at: at,
    category_id: food.clone(),
    note: Some("境外餐饮".into()),
    total_amount_cents: 10_000,        // 100.00 USD（花费币种）
    currency: Some("USD".into()),
    actual_amount_cents: Some(73_000), // 730.00 CNY（结算币种）
    settlements: vec![SettlementInput {
        account_id: bank.clone(),
        amount_cents: 73_000,
    }],
    tag_ids: vec![],
})?;
```

- 花费币种与结算币种不同时，`actual_amount_cents` **必须**显式填写。
- Core 不做汇率换算，也不保存汇率。
- 花费金额用于预算/分类统计，实际金额用于账户余额/净资产。

### 收入

```rust
use tallytrail_core::CreateIncomeInput;

core.create_income(CreateIncomeInput {
    occurred_at: at,
    category_id: salary.clone(),       // 必须是 INCOME 分类
    note: Some("工资".into()),
    total_amount_cents: 2_000_000,
    currency: None,
    actual_amount_cents: None,
    settlements: vec![SettlementInput {
        account_id: bank.clone(),
        amount_cents: 2_000_000,
    }],
    tag_ids: vec![],
})?;
```

### 转账

```rust
use tallytrail_core::CreateTransferInput;

core.create_transfer(CreateTransferInput {
    occurred_at: at,
    from_account_id: bank.clone(),
    to_account_id: wallet.clone(),
    amount_cents: 100_000,
    note: Some("补充零花钱".into()),
    tag_ids: vec![],
})?;
```

- 两个账户必须币种相同且不相同账户。
- 转账生成一出一入两条结算行，不改变净资产，不计入收支统计。
- 转账没有分类。

## 7. 退款与报销

退款/报销都指向原支出，并继承原交易的花费币种与分类。

```rust
use tallytrail_core::{CreateRefundInput, CreateReimbursementInput};

core.create_refund(CreateRefundInput {
    occurred_at: at,
    ref_txn_id: expense_id.clone(),
    note: Some("部分退款".into()),
    total_amount_cents: 2_000,
    actual_amount_cents: None,
    settlements: vec![SettlementInput {
        account_id: wallet.clone(),
        amount_cents: 2_000,
    }],
    tag_ids: vec![],
})?;

core.create_reimbursement(CreateReimbursementInput {
    occurred_at: at,
    ref_txn_id: expense_id,
    note: Some("公司报销".into()),
    total_amount_cents: 3_000,
    actual_amount_cents: None,
    settlements: vec![SettlementInput {
        account_id: reimburse_account.clone(),
        amount_cents: 3_000,
    }],
    tag_ids: vec![],
})?;
```

规则：

- 原交易必须存在、类型为 `EXPENSE`、状态为 `CONFIRMED`。
- 退款/报销金额不能超过原支出；同类累计也不能超过原支出。
- 退款结算行角色为 `RECEIPT`，报销为 `REIMBURSE_SOURCE`。
- 退款/报销的实际结算币种可以与花费币种不同；不同时必须显式填写 `actual_amount_cents`。
- 冲减按退款/报销自身 `occurred_at` 所在周期计算，不回溯原交易日期。
- 原支出存在未作废的退款/报销时不能作废，返回 `HasActiveDependents`。

## 8. 作废

```rust
core.void_transaction(txn_id, "录入错误".into())?;
```

- 作废是软删除：状态改为 `VOIDED`，记录作废时间与原因。
- 所有统计、余额、预算、净资产只计算 `CONFIRMED`。
- 不能重复作废。
- 支出有未作废的退款/报销时禁止作废。
- 贷款放款有未作废的还款时禁止作废。

## 9. 贷款

### 创建贷款

```rust
use tallytrail_core::CreateLoanInput;

let loan = core.create_loan(CreateLoanInput {
    lender: "某银行".into(),
    principal_cents: 500_000,
    currency: None,               // 默认 CNY
    interest_rate_bp: 450,        // 年化 4.50%
    start_at: at,
    term_months: Some(12),
    account_id: Some(bank.clone()), // 可选，币种必须一致
    note: None,
})?;
```

### 放款

```rust
use tallytrail_core::CreateLoanDisbursementInput;

core.create_loan_disbursement(CreateLoanDisbursementInput {
    occurred_at: at,
    loan_id: loan.clone(),
    amount_cents: 500_000,
    account_id: bank.clone(),
    note: None,
    tag_ids: vec![],
})?;
```

- 放款计入账户资产，但不计入收入。
- 放款账户币种必须等于贷款币种。

### 还款

```rust
use tallytrail_core::CreateLoanRepaymentInput;

core.create_loan_repayment(CreateLoanRepaymentInput {
    occurred_at: at,
    loan_id: loan,
    actual_amount_cents: 103_000,  // 1030.00
    principal_part_cents: 100_000, // 本金 1000.00
    interest_part_cents: 3_000,    // 利息 30.00
    account_id: bank.clone(),
    category_id: None,             // 利息分类，可空；非空必须是 EXPENSE
    note: Some("第一期".into()),
    tag_ids: vec![],
})?;
```

- `本金 + 利息 = 实际还款金额`。
- 本金不能超过剩余未还本金。
- 利息计入收支汇总；若指定分类，也进入分类支出序列。
- 本金与利息都不计入预算。
- 未还本金 = 本金 − 所有已确认还款的本金部分；结清状态动态推导。
- 已结清的贷款不能继续还款。

查询：

```rust
let balance = core.loan_outstanding(&loan_id)?;
println!("未还本金: {}", balance.outstanding_cents);

for loan in core.list_loans()? {
    println!("{} {} {}", loan.lender, loan.outstanding_cents, loan.status);
}
```

## 10. 查询流水

```rust
use tallytrail_core::{TransactionFilter, TxnStatus, TxnType};

let rows = core.list_transactions(TransactionFilter {
    from_at: Some(month_start),
    to_at: Some(month_end),
    types: Some(vec![TxnType::Expense, TxnType::Refund]),
    category_id: Some(food.clone()),
    account_id: Some(bank.clone()),
    tag_ids: Some(vec![tag.clone()]), // 必须同时具备所有给定标签
    currency: Some("CNY".into()),
    status: Some(TxnStatus::Confirmed), // None 表示全部状态
    limit: Some(50),
    offset: Some(0),
})?;
```

- `category_id` 为一级分类时自动包含其二级分类。
- `to_at` 为开区间上界。
- 返回 `TransactionView`，包含结算行与标签。
- 单笔详情用 `get_transaction(id)`，额外返回完整结算/标签信息。

## 11. 统计与三套口径

```rust
let summary = core.income_expense_summary(month_start, month_end)?;
for row in summary.by_currency {
    let net = row.total_expense_cents
        - row.total_refund_cents
        - row.total_reimbursement_cents;
    println!(
        "{} 收入 {} 毛支出 {} 退款 {} 报销 {} 净支出 {}",
        row.currency,
        row.total_income_cents,
        row.total_expense_cents,
        row.total_refund_cents,
        row.total_reimbursement_cents,
        net
    );
}
```

| 字段 | 含义 |
| --- | --- |
| `total_income_cents` | `INCOME` 的 `total_amount_cents` |
| `total_expense_cents` | `EXPENSE` 的 `total_amount_cents`（毛支出） |
| `total_refund_cents` | `REFUND` 的 `total_amount_cents` |
| `total_reimbursement_cents` | `REIMBURSEMENT` 的 `total_amount_cents` |
| 净支出 | 毛支出 − 退款 − 报销 |
| 贷款利息 | 计入 `total_expense_cents`；本金、放款、转账不计入 |

分类时间序列：

```rust
use tallytrail_core::Granularity;

let points = core.category_spending_series(
    food.clone(),
    month_start,
    month_end,
    Granularity::Monthly,
)?;
```

- 传入一级分类时包含其下所有二级分类。
- 退款/报销按负值冲减。
- 贷款利息按 `category_id` 计入；本金不计入。
- 若区间内没有任何该分类交易，返回空 `Vec`（不会补零）。
- 只有存在交易的币种才会产生数据点。

## 12. 账户余额

```rust
let balance = core.account_balance(&bank, as_of)?;
let all = core.list_account_balances(as_of)?;
```

余额 = 初始余额 + 所有 `CONFIRMED` 结算行（`PAYMENT` 减、`RECEIPT`/`REIMBURSE_SOURCE` 加），按账户币种累计。

`as_of` 为闭区间截止时刻（包含该秒）。UI 若传“某日结束”，应为该日最后一秒。

## 13. 预算

### 创建

```rust
use tallytrail_core::{BudgetScope, CreateBudgetInput, PeriodType};

let budget = core.create_budget(CreateBudgetInput {
    name: "十月餐饮".into(),
    scope: BudgetScope::CategoryL1,       // TOTAL / CATEGORY_L1 / CATEGORY_L2
    category_id: Some(food.clone()),      // TOTAL 时必须是 None
    period_type: PeriodType::Monthly,     // MONTHLY / YEARLY / CUSTOM
    amount_cents: 30_000,
    currency: None,                       // 默认 CNY
    start_at: None,
    end_at: None,
    rollover: false,                      // 第一版固定按 0 处理
})?;
```

规则：

- `TOTAL` 不能指定分类；`CATEGORY_L1`/`CATEGORY_L2` 必须指定对应层级分类。
- `CUSTOM` 必须同时提供 `start_at`、`end_at`，且 `start_at < end_at`。
- `rollover` 当前保留字段，始终按 `false` 存储。

### 查询使用情况

```rust
let usage = core.budget_usage(&budget, now)?;
println!(
    "预算 {} 已用 {} 剩余 {} 周期 [{}, {})",
    usage.name,
    usage.used_cents,
    usage.remaining_cents,
    usage.period_start_at,
    usage.period_end_at
);

let all = core.list_budget_usage(now)?; // 只返回当前处于周期内的启用预算
```

计算口径：

```text
已用 = 周期内 CONFIRMED EXPENSE 的 total_amount_cents
     − 同分类 REFUND 的 total_amount_cents
     − 同分类 REIMBURSEMENT 的 total_amount_cents
```

- 只统计 `txn.currency == budget.currency` 的交易。
- 组合支付按 `total_amount_cents` 计。
- 一级分类预算包含其下二级分类。
- 退款/报销按自身发生时间计入所在周期。
- **所有 `LOAN_*` 交易都不计入预算（含本金与利息）。**
- 周期边界左闭右开。
- 已用可能为负（退款超过本期支出），`remaining_cents` 可能大于预算金额。

管理：

```rust
let budgets = core.list_budgets(true)?;      // true 包含停用
core.set_budget_active(budget.clone(), false)?;
core.delete_budget(budget)?;
```

`list_budget_usage` 会跳过停用预算，以及 `as_of` 不在周期内的 `CUSTOM` 预算。

## 14. 净资产

```rust
let points = core.net_worth_series(
    month_start,
    month_end,
    Granularity::Monthly,
)?;

for point in points {
    for row in point.by_currency {
        println!(
            "{}: 资产 {} − 负债 {} = 净资产 {}",
            row.currency,
            row.total_assets_cents,
            row.total_liabilities_cents,
            row.net_worth_cents
        );
    }
}
```

- 资产 = 所有账户余额之和（按币种）。
- 负债 = 贷款未还本金（按币种）。
- 未来起始的贷款不计入历史时点。
- 每个时间点的 `as_of` 取桶结束前 1 秒，且不超过 `to_at`。
- 转账是账户内部抵消，不影响净资产。
- 不做跨币种合并或汇率折算。

## 15. 错误处理

```rust
use tallytrail_core::{CoreError, CoreResult};

match core.create_expense(input) {
    Ok(id) => println!("已创建 {id}"),
    Err(CoreError::NotFound) => eprintln!("分类或账户不存在"),
    Err(CoreError::ValidationError(message)) => eprintln!("输入不合法: {message}"),
    Err(CoreError::HasActiveDependents) => eprintln!("存在未作废的关联交易"),
    Err(CoreError::MixedCurrencySettlement) => eprintln!("结算账户币种不一致"),
    Err(CoreError::CategoryInUse) => eprintln!("分类被引用"),
    Err(CoreError::AmountOverflow) => eprintln!("金额溢出"),
    Err(CoreError::DbError(message)) => eprintln!("数据库错误: {message}"),
    Err(CoreError::InvalidDirection) => eprintln!("交易方向不匹配"),
}
```

| 错误 | 触发场景 |
| --- | --- |
| `NotFound` | 账户/分类/标签/交易/贷款/预算不存在 |
| `ValidationError` | 参数、层级、金额、时间、币种、状态等校验失败 |
| `HasActiveDependents` | 作废被未作废的退款/报销/还款拦截 |
| `InvalidDirection` | 结算方向与交易类型不匹配 |
| `MixedCurrencySettlement` | 同一交易结算账户币种不一致 |
| `CategoryInUse` | 删除或改 `kind` 时分类仍被引用 |
| `AmountOverflow` | `i64` 分累加/累减溢出 |
| `DbError` | SQLite/迁移/锁错误 |

UI 层只做展示映射，不要重新解释业务错误。

## 16. 并发

```rust
let core = CoreHandle::open("my.db")?;
let worker = core.clone();

std::thread::spawn(move || {
    worker.create_tag("异步标签".into()).unwrap();
});
```

- `CoreHandle` 内部串行化所有数据库操作。
- 每次写操作是一个事务，失败自动回滚。
- 不要在持有 `CoreHandle` 的同时用其他连接直接写同一个 `.db`。
- 长耗时统计会持有连接锁；大批量导入建议分批提交。
